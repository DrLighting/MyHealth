## Descrição
Este trabalho visa construção de uma carteira digital de vacinação. 
O projeto consta com cadastro dos usuários, criação de certificados de vacinação, edição e exclusão dos memsmo. Manuputação direta do DOM HTML

## Instruções de Instalação
1. Clone o projeto em sua maquina
2. Edite o arquivo *fire_config.js* que ira estar em */src_web/config/* com suas api keys do firebase
3. Rode a página *index* em *src_web/index/intex.html* via live server
4. Projeto já deve está pronto para uso
